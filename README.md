# 📝 Notes Web & Mobile App

Легкий, быстрый и современный сервис заметок с поддержкой Markdown, локальным хранением данных и возможностью установки на Android как нативное PWA-приложение.

---

## ✨ Возможности

- Markdown-редактор заголовки, списки, блоки кода, цитаты с живым предпросмотром в реальном времени.
- Оффлайн-работа все заметки хранятся локально в `localStorage` браузера — интернет нужен только для первой загрузки страницы.
- Организация поиск по тексту и заголовкам, система тегов, закрепление важных заметок (Pin).
- Темы оформления светлая и тёмная темы с автоматическим переключением.
- Резервное копирование экспорт и импорт всей базы в формате JSON, а также скачивание отдельных заметок как `.md` файлов.
- Кроссплатформенность адаптивный интерфейс под смартфоны, планшеты и десктопы.
